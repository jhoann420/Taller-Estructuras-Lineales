
# Taller de Estructuras de Datos Lineales

Este repositorio contiene la solución de **15 ejercicios prácticos de Estructuras de Datos Lineales**, desarrollados en Java.

Los ejercicios permiten practicar diferentes conceptos relacionados con el manejo de **arreglos, ArrayList y matrices**, además de estructuras de control y operaciones sobre colecciones de datos.

## Contenido

El taller incluye ejercicios relacionados con:

* Arreglos de números primos.
* Arreglos de números pares.
* Generación y procesamiento de números aleatorios.
* Cálculo de factoriales.
* Búsqueda de números mayores y menores.
* Inversión de números.
* Uso de `ArrayList`.
* Inserción y eliminación de elementos.
* Conteo de frecuencias.
* Ordenamiento de listas.
* Separación de números pares e impares.
* Recorrido y búsqueda en matrices.
* Operaciones con diagonales.
* Comprobación de matrices simétricas.
* Matrices transpuestas e intercambio de filas.

## Tecnologías utilizadas

* **Java**
* `Scanner`
* `ArrayList`
* Arreglos unidimensionales
* Matrices bidimensionales
* `Math.random()`
* `Collections`

## Objetivo

El objetivo del taller es fortalecer la comprensión y aplicación de estructuras de datos básicas mediante la resolución de problemas prácticos, trabajando con recorridos, búsquedas, ordenamientos, inserciones, eliminaciones y operaciones sobre arreglos y matrices.
